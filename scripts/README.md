# Maintenance scripts

`scripts/ci/selection.py` validates ownership and computes impact.
`scripts/ci/runner.py` installs and executes a selected owned suite.
See [CI instructions](../docs/ci.md). Current user commands and engineering
recipes are in [the workflow](../docs/current-workflow.md).

Historical milestone validators and formal experiment scripts remain in the
pre-consolidation source archive; see [the archive index](../docs/archive/index.json).
Their recorded results retain their original source and cannot certify the new
runtime. No formal experiment is launched by this consolidation.
