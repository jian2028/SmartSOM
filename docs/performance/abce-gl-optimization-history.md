# A–L 性能优化尝试与整合记录

本记录保留采纳和未采纳的尝试。数值来自两轮已验收的本地固定状态短测；不把不同阶段的计时拼成同一对照，也不把历史 CI 当作本 PR 新提交的 CI。

## 当前整合策略

| 条件 | 本轮选择的实测组合 | 本分支实际启用 |
| --- | --- | --- |
| DQN Matrix / Grid | ABCE + GHIJKL | ABCE + G/H/I + L；J/K 是 PPO 专用的已测负对照，DQN 没有相应运行工作 |
| PPO Matrix / Grid | ABCE + GHIJ | ABCE + G/H/I/J；不启用 K，检查点保留 L 之前的路径 |

统一源码按算法选择路径，不根据测试名称或地图硬编码。Matrix/Grid 使用相同的算法规则。当前整合新增了 DQN 专用流式哈希的条件，并保留远端 ABCE 的回归测试；它是一个新源码版本，需独立 CI，下面的历史秒数不声称已在新组合树上复测。

## 尝试了什么

| 方案 | 尝试 | 最终处理及原因 |
| --- | --- | --- |
| A | DQN 按需构造 value 输入 | 采纳；保留终止、截断、状态化/自定义网络及钩子回退 |
| B | PPO 延后 bootstrap 到 rollout 边界 | 采纳；续训保留延后请求，DQN 不使用该 PPO 工作 |
| C | 过滤后复制观测、请求内建立语义 job 索引 | 采纳；同 tick 变化和所有权隔离保持 |
| D | 继续消除边界双重复制 | 未产生新优化补丁；两份记录有独立可变性契约，保留原行为。不可填造提速值 |
| E | 缓存未变化的模型包和准备元数据 | 采纳；保持内容敏感失效、保存频率和原子发布，接受额外内存 |
| F | PPO GAE/训练数组缓存 | 不采纳；严格数值检查通过，但独立 F/ABCEF 未证明训练提速，且增加峰值内存 |
| G | 标量和原生容器复制快路径 | 组合中采纳；保留别名、循环容器、memo 和扩展钩子回退 |
| H | 观测投影及事务图/工序描述符特化 | 独立 H 四项不保留；实际 GHIJ/GHIJKL 组合仍按其整体测量选择，不宣称 H 有独立因果收益 |
| I | 记忆化重复参考工作量计算 | 组合中采纳；最明显收益在 PPO，保持内容失效和浮点求和顺序 |
| J | PPO actor/critic 分支输出拆分 | PPO 采纳；自定义/钩子/随机 GRU/共享图走原完整路径。DQN 为实际负对照 |
| K | 复用 PPO 诊断归约 | 不启用；变化很小或不一致，未见内存改善。DQN 为实际负对照 |
| L | 序列化时流式计算 continuation 哈希 | 仅 DQN 启用，主要理由是峰值内存降低；PPO 保留 GHIJ 的保存路径 |

“conditional”表示保留为候选/组合构件，不能自动解释为单独源码已被采纳。全部 24 条 A–F 和 44 条 G–L 的逐条件原始取舍理由保存在 [结果 JSON](abce-gl-results.json)。

## 测量范围与复核入口

- A–F：2026-10-22 轮；28 个实际训练条件组及对应验证组，每组三次。A 的 PPO、B/F 的 DQN 没有独立计时；D 没有新补丁。这些空缺明确保留，不扩写为全四条件结论。
- G–L：singles-v2 与 combinations-v1 分别使用本阶段新 ABCE 对照；六个单项和五个组合均测 DQN/PPO × Matrix/Grid。共 624 原生步骤、52 个条件组，每组训练和验证各三次。
- 训练主窗口为 1024→1536（512 tick），独立验证为 128 tick，含模型加载；warm/restore/stage/trace 不混入 plain3 中位数。
- 固定起点与线程设置；严格核心/优化器/采样/RNG/恢复及有序批次对照。阶段占比为插桩诊断，优化器已包含内部网络工作，不能再叠加 inclusive 函数耗时。
- H 的可比类别为 observation + observation_copy + copy 合计；不能把类别搬移当成提速。
- 进程 RSS 是计时结束时的进程累计峰值，含初始化和恢复；不是阶段独立分配。
- G→GH 跨阶段，仅描述性比较；两个 ABCE n=3 不合并为 n=6，独立百分比不相加。
- [计时 CSV](abce-gl-timings.csv)：160 行，保留三次原始秒数、中位数/范围、RSS、对应阶段对照。
- [阶段 CSV](abce-gl-stages.csv)：训练/验证互斥类别的秒数、root 和占比。
- [结果与证据摘要 JSON](abce-gl-results.json)：原始结果字节 SHA、源身份摘要、人工决策、限制和归档索引。大型 pickle/trace/模型包不提交。
